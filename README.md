## Project Information
The app will be updated every other day; for example, a version is released on the 1st, and a new update comes out on the 3rd. How to break down the update version: for example, the current version is 0.221.1. The “0” indicates the version; “0” means it’s a beta version, and “1” means it’s the final version it will be the player’s latest version. “221” is the build number; “22” is the day the build was compiled, 1 is the last digit of the hour when the build was compiled, and .1 is the version number indicating the sequence of releases; for example, 0.235.2 would be the second version in the sequence.
