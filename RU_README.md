## О проекте
Это новый плеер, разработанный в стиле Material 3 Express. Будут выпускаться обновления, хотя, в общем-то, их не понадобится слишком много, так как проект находится в стадии разработки, и новые функции будут добавляться по мере его развития.

## Как я работаю над проектом
Я работаю над проектом на своём телефоне с помощью приложения Code on the Go, так как Android Studio на моём компьютере не работает.

## Информация о проекте
Приложение будет обновляться через день; например, версия выпускается 1-го числа, а новое обновление 3-го. Как расшифровать номер версии обновления: например, текущая версия — 0.221.1. Цифра «0» обозначает версию; «0» означает, что это бета-версия, а «1» — что это финальная версия, которая станет самой последней для плеера. «221» — это номер сборки; «22» — день, когда была скомпилирована сборка, «1» — последняя цифра часа, когда была скомпилирована сборка, а «.1» — номер версии, указывающий на последовательность выпусков; например, 0.235.2 будет второй версией в этой последовательности.
